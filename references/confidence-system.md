# 置信度与回测体系

## 置信度计算

每个预测注有6个分项评分，加权合成最终置信度（0-100%）。

### 分项详情

| # | 分项 | 权重 | 计算逻辑 |
|---|------|------|----------|
| 1 | 回测均分 | 40% | `avg(近30期回测得分) / 12`，反映策略历史表现 |
| 2 | 信号强度 | 25% | 选中号码的频率(或遗漏值)相对于全池平均的比值，归一化到0-100 |
| 3 | 结构合理 | 15% | 奇偶2-3(+满分)、大小2-3(+满分)、未满足扣分 |
| 4 | 重号匹配 | 10% | `min(与上期重号数 / 2, 1.0)` |
| 5 | 位势偏差 | 5% | 龙头(最小号)和凤尾(最大号)偏离历史均值的程度，越小越好 |
| 6 | 连号加分 | 5% | 有连号=100%，无连号=50% |

### 各策略的信号强度计算方式

不同策略用不同的参考数据计算信号强度：

| 策略 | 参考数据 | 窗口 | 特殊处理 |
|------|----------|------|----------|
| 热号策略 | freq | 50期 | — |
| 冷号策略 | missing | 100期 | — |
| 均衡策略 | freq | 100期 | fallback else 分支 |
| 012路策略 | freq + route count | 50期 | 前区加 route_counts×0.5 |
| 尾号策略 | freq + tail count | 50期 | 前区加 tail_counts×0.3 |
| 分区策略 | freq | 30期 | — |
| 回补策略 | missing | 100期 | — |
| 综合策略 | freq | 100期 | fallback else 分支 |
| 马尔科夫链 | freq | 100期 | — |
| 遗传算法 | freq | 100期 | — |
| AI集成学习 | freq | 100期 | — |
| 杀号策略 | freq | 50期 | — |
| 黄金斐波那契 | freq | 50期 | — |
| AC值同期对比 | freq | 100期 | — |
| 六行六列图 | freq | 30期 | — |

### 信号强度通用公式

```python
# 前区信号
avg_all = mean(all_numbers_freq_or_missing)
avg_picked = mean(picked_numbers_freq_or_missing)
strength_f = min(avg_picked / avg_all, 2.0) / 2.0  # 0-1范围

# 后区信号同理
strength_b = min(avg_picked / avg_all, 2.0) / 2.0

# 合成
signal_strength = strength_f * 0.7 + strength_b * 0.3
```

## 回测体系

### 回测方式

30期滑动窗口回测，每期取策略的3注中**最佳得分**：

```python
def backtest(strategy_fn, rows, test_window=30, **kwargs):
    for i in range(test_window):
        bets = strategy_fn(rows[i:], **kwargs)  # 只用i之前的数据
        real = rows[i]                            # 当期实际开奖
        best = max(hit_score(fh, bh) for each bet)
```

### 排名算法

综合排名分 = 均分×50% + 稳定度×30% + 高分率×20%：

| 维度 | 公式 | 含义 |
|------|------|------|
| 均分 | `avg(scores) / 12 × 100` | 历史平均表现 |
| 稳定度 | `(1 - std(scores)/12) × 100` | 得分波动性（越稳定越好） |
| 高分率 | `count(score≥4) / 30 × 100` | 中奖级别命中率 |

得分≥4 意味着：前区命中≥2 + 后区命中≥0，或前区≥1 + 后区≥2，或前区=0 + 后区≥4（不可能）。

当反馈数据≥3期时，输出逐期趋势矩阵：

```
  期号     热号  冷号  均衡  012路  尾号  分区  回补  综合  马尔科夫  遗传  AI  杀号  黄金  AC  六行
  26051     3     0     2     5     1     4     0     3      2      4    5    3    2    1    0
  26050     2     5     1     3     0     2     6     1      3      2    4    0    5    3    2
  ...
```

每格为该策略该期的最佳得分(0-12)。用于直观判断各策略在不同时期的冷热交替。

## CSV数据格式

文件: `dlt_100.csv`, 编码: UTF-8-BOM

```
期号,开奖日期,前区1,前区2,前区3,前区4,前区5,后区1,后区2
26051,2026-05-11,3,12,18,25,33,5,9
```

- 第一行为 header
- 按期号倒序排列（最新在前）
- 号码为整数，无前导零
